Byte-exact, or it doesn't ship.

LEXORA canonicalizes a text collection into deterministic UTF-8 bytes, then compresses those bytes with a guarantee that holds for every input. The core invariant is deliberate: canonicalization may lose information relative to the source; compression after it may never lose a single byte.

What it is

Byte-exact losslessness

The round-trip is verified before anything is written. A failed comparison stops the write rather than warning about it.

core invariant

Conservative canonicalization

A versioned, deterministic rule set — lexcan-0.1, CAN-R01/R02/R05 — with golden test vectors and a whitelist contract: non-matching bytes pass through unchanged.

versioned rules

Cost-driven selection

Candidates compete against pinned baselines under a total-serialized-byte model — every byte of header, index and payload counts, not just the compressed stream.

measured, not assumed

The .lxz v0 container

128-byte header, one complete zstd frame per block, per-block SHA-256, 40-byte trailer. Every block is decode-verified and the write is atomic.

frozen per ADR-0007

A real CLI

Nine tested subcommands with a stable exit-code contract (0–7), exercised by 502 tests including reader/writer fuzzing and real-signal interruption tests.

canon · zround · pipe · pack · unpack · verify · inspect · batch · doctor

Built for low resources

Designed to run inside a ~4 GiB RAM budget using bounded, block-based streaming. English, Hindi and Gujarati are design targets.

bounded blocks

Where it stands

No releases. No stable API. Install from a source checkout, and pytest -q is the local gate.

The container is .lxz v0 at major version 0 and the GUI is unreleased — M1–M3 milestones only. Phase 1 is complete; this page will say phase 2 when phase 2 exists.

Quickstart

# from a source checkout — there is no release yet
git clone https://github.com/drsamonline/lexora.git
cd lexora
pytest -q                       # the local gate: 502 tests

# the round-trip that has to hold
lexora pack corpus/ -o corpus.lxz
lexora verify corpus.lxz        # decode(encode(C)) == C, or it fails
