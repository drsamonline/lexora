# LEXORA 0.2.0-alpha.1 — 2026-11-18

**Alpha: not for production data.** The canonicalisation rule table is not frozen, so a 0.x release
can change what an archive contains.

## What this release adds

**`--language` on `canon` and `pack`.** The plugin seam was proven by two languages but reachable
only from Python — a plugin could be imported and called, and nothing a user typed could select it.
`lexora canon --language hi` now cleans with the Devanagari rules, and `lexora pack --language hi`
writes `hi-1` into the `canonicalizer_version` header field.

Two properties are pinned by `tests/test_cli_language.py`:

- the default path is **byte-identical** to before — `en` and no flag produce the same archive bytes,
  so no existing archive moves;
- an unknown id is a **usage error (exit 2) naming the installed plugins**, not a traceback.

Stated rather than hidden: a plugin declares a whole-document `canonicalize`, so a plugin path
buffers instead of streaming. That is in `docs/CLI_REFERENCE.md`.

## What this release fixes

**The version a user reads is the version that shipped.** The previous cut bumped `pyproject.toml`
and the changelog and left `src/lexora/__init__.py` behind, so `lexora --version` answered a version
that never shipped. The README badge and `docs/CLI_REFERENCE.md` were three releases further behind.
All four surfaces now agree, and `test_readme_claims.py::test_the_version_a_user_reads_is_the_version_that_shipped`
reads the badge and the CLI reference so prose cannot drift unnoticed again.

**This release is the test of that fix**: the wheel installed into a clean virtualenv answers
`lexora 0.2.0a1`, which is the version in the filename.

## What is NOT in this release, said plainly

- **No benchmark numbers.** Release precondition **R5 — the protocol-scope benchmark — is still
  unmet**, so there are no compression figures here and none are claimed. `BENCHMARK_RESULTS.md`
  says the same.
- **The rule table is not frozen.** `CANONICALIZATION.md` marks it Proposed; nine golden vectors
  exist and freeze needs the owner's sign-off.
- **`.lxdb` is not here.** Designed, gated behind R5.
- **No PyPI publication.** The wheel is attached to this release; nothing is uploaded to an index.
